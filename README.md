# Financial Cybersecurity Awareness Portal

A simple interactive website that helps users learn about financial cybersecurity and safer online banking practices.

## Features

* Information about common cyber threats such as phishing, malware, social engineering, and identity theft.
* Cybersecurity checklist with a dynamic security score.
* Interactive phishing awareness quiz.
* Responsive design for desktop and mobile devices.
* Deployed using GitHub Pages.

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages
